AKIFA DONAT WEBSITE — PANDUAN SINGKAT

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder akifa-donat-website.
3. Klik dua kali index.html untuk membuka website di browser.
4. Halaman admin: buka admin.html.
5. Password demo admin: akifa123.

FITUR
- Website responsif untuk HP dan desktop.
- Katalog 10 varian donat.
- Form pemesanan paket 3 donat seharga Rp10.000.
- Pesanan disimpan pada LocalStorage browser.
- Tombol kirim detail pesanan ke WhatsApp Akifa Donat.
- Dashboard admin demo untuk melihat pesanan.

PENTING
- Foto produk asli belum disertakan dalam file yang dikirim. Kartu produk saat ini memakai ilustrasi donat CSS sebagai placeholder.
- Ganti ilustrasi dengan foto asli setelah foto produk tersedia.
- Nomor WhatsApp disetel ke 0815-7844-4386 dan Instagram ke @tuku.donatt berdasarkan brief.
- Dashboard ini masih versi demo. LocalStorage hanya menyimpan data pada browser/perangkat yang sama, bukan database online.
- Password admin demo tertulis di file JavaScript, jadi jangan gunakan untuk website produksi. Untuk penggunaan sungguhan, perlu database dan autentikasi aman (misalnya Firebase).
